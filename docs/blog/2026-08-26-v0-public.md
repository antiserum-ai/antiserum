# v0.1.0 public CLI

Initial public v0. Local CLI only. No telemetry. Package version `0.1.0` is `receipt.version`.

Shipped on that tag:

- `antiserum scan` for text JSONL and `.txt` (Alpaca, ShareGPT / messages, prompt+completion)
- Five checks: trigger n-grams, label flips, duplicate inject, stat outliers, signature hit
- Deterministic receipt: dataset hash, scanner version, local pack identity
- Offline confirm loop: `judge`, settle leftovers, `propose` signatures
- Local allowlist for known false alarms
- Reference corpus and `make reproduce` / `make eval`
- `--fail-on` exit-code contract for CI

The repo is the product. There is no hosted scan and no Hub client. Later capability ships (HTML/CSV/SARIF exports, more checks, field-hunt canaries) are dated posts in this folder and lines in [CHANGELOG.md](https://github.com/antiserum-ai/antiserum/blob/main/CHANGELOG.md).
